# SpendWise – Budget Tracker

## Project Description

SpendWise is an interactive budget tracking application that helps users manage their budgets and expenses. Users can set a budget, add expenses, calculate total spending, view their remaining balance and delete expenses.

The website is built using HTML, CSS and JavaScript and published online using GitHub and Netlify.

- HTML5
- CSS3
- JavaScript
- Git

- Netlify

One challenge was connecting GitHub to Netlify. I resolved this by authorizing Netlify to access my GitHub repository.

Another challenge was ensuring that HTML, CSS and JavaScript files loaded correctly. I checked the file names, links and deployment settings.
